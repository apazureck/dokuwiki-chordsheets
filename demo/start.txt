====== DokuWiki Chordsheets ======

{{:wiki:logo.png?220|DokuWiki Chordsheets logo}}

**Turn plain-text chord charts into interactive song sheets.**

Keep the simplicity of DokuWiki markup while giving musicians readable sections, chord diagrams, transposition, and an export-friendly layout.

> [[#live_demo|Explore the live examples]] · [[#installation|Install the plugin]] · [[https://github.com/apazureck/dokuwiki-chordsheets|View the project on GitHub]]
> **New:** [[#feature_tour|Try the complete feature tour]] with ukulele, inline chords, voicings, tablature, notation, and document export.

===== Play it, don't just document it =====

The plugin keeps songs easy to edit and pleasant to use during rehearsal, lessons, or a gig.

  * **Chord diagrams on demand** — Hover a highlighted chord or focus it with the keyboard to see its fingering.
  * **Transpose while publishing** — Shift a complete sheet by semitones without rewriting every chord.
  * **Readable song sections** — Intro, verse, chorus, bridge, and refrain remain easy to scan.
  * **Export-friendly output** — Copy the rendered song into a document when you need a printable handout.

===== Live demo =====

These short examples use original demo lyrics. Try the highlighted chords and compare the original progression with its transposed version.

==== Example 1 — A simple campfire progression ====

<chordSheet 0>
[Intro]
Am    F     C     G

[Verse]
C
Morning finds the open road
G
Every mile becomes a note
Am
Carry the rhythm, travel light
F                         C
Sing the map into the night

[Chorus]
F               C
Pages turn and voices rise
G                     Am
Chords are waiting between the lines
</chordSheet>

**Try it:** Hover or focus //Am//, //F//, //C//, or //G// to open the chord diagram.

==== Example 2 — The same idea, two semitones higher ====

The number in the opening tag is the transposition in semitones. Negative numbers transpose down.

<chordSheet 2>
[Intro]
Am    F     C     G

[Verse]
C
Write it once and change the key
G
Keep the song easy to read
Am
Every chord moves as a set
F                         C
No manual rewriting or regret
</chordSheet>

==== Example 3 — Extended and slash chords ====

<chordSheet 0>
[Verse]
Cmaj7        G/B
Leave a little room to breathe
Am7          Fadd9
Color every line with harmony

[Bridge]
Dm7          G7
Turn the page and count us in
Cmaj7
Let the next refrain begin
</chordSheet>


===== Feature tour =====

The current release brings the completed wishlist together in one workflow. Every example below is live: use the keyboard as well as the pointer, change a guitar voicing, and copy a clean version into a document when you are done.

==== Inline chords and slash bass ====

Inline chords keep compact lead sheets readable. Slash chords expose their bass note separately for themes and export tools.

<chordSheet 0 title="Night Lines" author="Demo Ensemble">
[Verse]
Walk [C] home with the melody above us and the (G/B) bass leading down.
Keep [Am7] time while the [Fadd9] streetlights fade.
</chordSheet>

==== Tooltip alignment at both edges ====

The two chords below exercise both viewport edges. Their popovers stay inside
the browser while each arrow continues to point at its chord text.

<chordSheet 0 title="Tooltip Edge Check">
[Viewport edges]
C                                                       G
</chordSheet>

==== Long chord lines stay intact ====

Bars, repeat annotations, unknown stage notes, slash chords, spacing, and
trailing text must survive parsing without being merged into neighboring
chords.

<chordSheet 0 title="Long Line Regression">
[Mixed chord line]
C | G/B (2x) ??? | Am7    Fadd9 || Dm7/G  outro
</chordSheet>

==== Alternative voicings ====

Guitar chords use a compact visual **Fret** picker: **Open** and the fret numbers identify each actual neck position. Switch the selected shape between **Fretboard** and **Tab** without leaving the popover. Add an exact low-E-to-high-e shape such as ''C@{x,3,2,0,1,0}'' to the song source when the voicing is part of the arrangement. The orange **Pin** is the authored shape; alternatives are temporary previews and never rewrite the song.

<chordSheet 0 title="Voicing Lab">
[Progression]
C@{x,3,2,0,1,0}        G        Am       F
</chordSheet>

==== Ukulele and song metadata ====

Set ''instrument="ukulele"'' on the opening tag to switch to four-string GCEA diagrams. Title, author, and date become a structured song header.

<chordSheet 0 instrument="ukulele" title="Four Strings, One Song" author="Chordsheets Demo" date="2026-07-30">
[Verse]
C        Am       F        G
Four strings, the same transposable song syntax.
</chordSheet>

==== Standalone JTab chord ====

<chordSheet 0>
%7/2.X/X.7/3.7/4.6/1.X/X[Bm7b5]
</chordSheet>

The original JTab custom-chord syntax remains supported for existing pages.
This example renders one explicitly authored ''Bm7b5'' shape.


==== Tablature and standard notation ====

Dedicated blocks keep JTab-compatible tablature and locally rendered ABC notation next to the lyrics.

<chordSheet 0 title="Tab and Notation Study" author="Chordsheets Demo">
[Tablature]
{{tab}}
$2 0 1 3 $1 0 3 | 022100
{{/tab}}

[Notation]
{{notation}}
X:1
M:4/4
L:1/4
K:C
C D E F | G A B c |
{{/notation}}
</chordSheet>

==== Configuration ====

Administrators can tune colors, fonts, independent chord and lyric sizes, spacing, section styling, tooltip behavior, metadata export, and the Word export font family in DokuWiki's Configuration Manager.

===== Write your first sheet =====

Wrap a plain-text song in ''chordSheet'' tags. Put chords on their own lines and use square brackets for section names.

<code xml>
<chordSheet 0>
[Intro]
Am    F     C     G

[Verse]
C
Your lyric line goes here
G
The next line follows the chords
</chordSheet>
</code>

  * ''&lt;chordSheet 0&gt;'' keeps the original key.
  * ''&lt;chordSheet 2&gt;'' transposes up two semitones; ''-2'' transposes down.
  * ''[Verse]'', ''[Chorus]'', and other bracketed labels create visible sections.
  * Chord-only lines are recognized automatically and keep their spacing.
  * Use ''[C]'' or ''(G/B)'' for inline chords inside a lyric line.
  * Use dedicated ''tab'' and ''notation'' blocks for tablature and standard notation.
  * Add ''instrument="ukulele"'', ''title'', ''author'', or ''date'' on the opening tag when needed.

===== Installation =====

  - [[https://github.com/apazureck/dokuwiki-chordsheets/archive/refs/heads/master.zip|Download the current project ZIP]].
  - Extract it and rename the extracted directory to exactly ''chordsheets''.
  - Copy that directory to ''lib/plugins/chordsheets/'' inside your DokuWiki installation.
  - Open any wiki page, add a ''&lt;chordSheet&gt;'' block, and save.

The resulting plugin path must look like this:

<code>
lib/
└── plugins/
    └── chordsheets/
        ├── syntax.php
        ├── script.js
        ├── style.css
        └── plugin.info.txt
</code>

For general extension administration, see the [[https://www.dokuwiki.org/plugins|official DokuWiki plugin documentation]].
